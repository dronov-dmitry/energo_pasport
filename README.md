# Энергетический паспорт здания — онлайн-калькулятор теплозащиты

> **Бесплатный онлайн-калькулятор** для расчёта энергетического паспорта здания по **СП 50.13330.2024**. Проверка теплозащиты ограждающих конструкций, расчёт **ГСОП** (градусо-суток отопительного периода), **сопротивления теплопередаче** (R-фактор), определение **класса энергетической эффективности** по приказу 399/пр.

## 🏢 О проекте

Веб-приложение для **расчёта энергетического паспорта здания** по нормам **СП 50.13330.2024** «Тепловая защита зданий». Позволяет выполнить полный расчёт теплозащиты ограждающих конструкций, определить **класс энергетической эффективности** и подготовить данные для энергопаспорта.

### Целевая аудитория

- **Проектировщики** — проверка соответствия теплозащиты нормам
- **Энергоаудиторы** — расчёт энергопаспорта для аттестации
- **Архитекторы** — подбор материалов и толщины утеплителя
- **Строители** — контроль качества теплозащиты

### ✨ Возможности

- Выбор **региона / населённого пункта** по климатическим данным (справочник с бэкенда).
- Задание **конструктивных фрагментов** ограждающих конструкций (слои материалов, толщины) и расчёт теплотехнических показателей.
- Параметры здания: этажность, объёмы, высота этажа, тип здания (жилое и др.).
- **Заселение и бытовые нагрузки**, вентиляция, рекуперация (упрощённая модель).
- Учёт **солнечных поступлений** через оконные проёмы по ориентациям (MVP).
- Загрузка справочника **материалов** и выполнение расчёта через API; отображение итогов паспорта.

### Импорт / экспорт настроек (JSON)

- Кнопки **«Импортировать JSON»** и **«Экспортировать в JSON»** в форме расчёта.
- Формат: `version: 1`, поля `region`, `cityId`, `buildingType`, `building`, `fragments` (см. `src/lib/buildingPassportDraft.ts`).
- В каждом слое `fragments[].layers[]` при **экспорте** в JSON попадают **`materialId`**, **`thickness`**, а также справочные **`name`** и **`density_rho`** (как в API материалов). Для расчёта по-прежнему используется только `materialId`; импорт читает эти поля для удобства, но подставляет форму по id из справочника.

## 📚 Нормативная база

Калькулятор использует актуальные строительные нормы и правила:

- **СП 50.13330.2024** «Тепловая защита зданий» — основной документ для расчёта теплозащиты
- **СП 23-101-2004** «Проектирование тепловой защиты зданий» — методика расчёта
- **ГОСТ 30494-2011** «Здания жилые и общественные. Параметры микроклимата»
- **Приказ Минстроя России №399/пр** «О классах энергетической эффективности зданий»
- **СП 131.13330.2020** «Строительная климатология» — нормативные значения температур
